# dum-e-portfolio

Concept repo for an interactive robot-arm character on his portfolio:
when a visitor asks for the resume, the arm animates in, opens a folder,
and hands it over. Monochrome (black/grey/white), Departure Mono,
JS + CSS animation.

Everything lives in [SEEDFILE.md](SEEDFILE.md).
